# Japan 2026 — audited travel planner

Static GitHub Pages project rebuilt from the existing `stanislavchernov2010-eng/Japane` repository and the uploaded itinerary PDF.

## Important
The GitHub connection available during this audit is read-only (`pull: true`, `push: false`), so the rebuilt files are supplied as a ZIP rather than committed directly to the repository.

## Scope
- 14 trip days in the public itinerary window: 18 Nov — 1 Dec 2026.
- Flight legs from the uploaded itinerary: 17 Nov — 2 Dec 2026.
- Tokyo → Kyoto → Osaka → Tokyo route retained.
- Original timings and notes retained where possible.
- Current source checks performed 28 Sep 2026.
- Unverified and conflicting values are deliberately visible.

## Files
- `index.html` — static planner
- `style.css` — responsive UI
- `script.js` — filtering, tabs, collapsible details, map links
- `itinerary.json` — structured route data
- `AUDIT.md` — audit findings and corrections
- `README.md` — project notes
- `assets/` — reserved for optional local assets

## Publish
Upload these files to the repository root and enable GitHub Pages from the `main` branch/root.

## Privacy
The uploaded itinerary contains passenger names, booking references and e-ticket numbers. Those credentials are intentionally **not copied into the public site**. Only travel-relevant dates, airports, flights and baggage rules are represented.
